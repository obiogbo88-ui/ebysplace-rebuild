# Shop Colour-Swatch Preview Notes

The upgraded shop page now presents a more polished customer buying flow with product cards, a right-side checkout panel on desktop, SEO metadata display, and colour-specific purchase actions. Clicking an available colour swatch updates the visible selected colour label and changes the add-to-bag action text. For example, selecting “30 Auburn” on Premium Braiding Hair updates the current colour state and changes the button to “Add 30 Auburn to bag,” confirming that the product presentation responds to customer colour selection.

The page remains readable in the current desktop preview, with high-contrast cream/gold action buttons against the dark luxury shop background. The available colour swatches are presented as accessible radio-style buttons with visible labels, helping customers understand which colour they are choosing before checkout.
