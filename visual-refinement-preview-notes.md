# Visual Refinement Preview Notes

Preview checked on 2026-05-01 at the current dev URL. The homepage now uses a warm cream/beige background close to the current Eby’s Place reference, with dark-brown navigation and high-contrast body text on cream sections. The About Us content appears near the bottom of the homepage after the newsletter signup, keeping the footer as the final site chrome. The implementation was kept visual-only: existing booking links, shop links, newsletter mutation, public/admin tRPC calls, AI Try-On navigation, and admin upload behaviour were not changed.
