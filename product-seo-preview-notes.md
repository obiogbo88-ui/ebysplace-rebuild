# Product SEO Preview Notes

The public shop now displays each product name, stock status, slug, public description, SEO title, and SEO description within responsive product cards. The basket column remains visible on desktop and stacks naturally with the product grid on smaller widths by using a constrained `minmax(0, 1fr)` grid and `min-w-0` safeguards.

The admin dashboard now includes a **Products, stock & SEO** section. Each product row exposes editable fields for product name, SEO slug, SEO page title, SEO meta description, public description, badge, stock quantity, and stock status. The admin preview confirms that these fields are visible in the dashboard and are linked to the same product data used by the public shop.
